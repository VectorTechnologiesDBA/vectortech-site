Vector++

The original Anki Vector Android app, patched to work with WirePod.

What it is

Vector++ is a patched version of the original Anki Vector Android app (1.5.0). Anki's cloud is gone, so the stock app has nothing to talk to. Vector++ replaces the app's server calls so it connects to WirePod instead.

Built by Hayes. Beta tested by Jaceroo404!

What works

Everything the old app did works.
